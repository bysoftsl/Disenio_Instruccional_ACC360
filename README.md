# ACC360 · Prototipo Moodle V2.0

Prototipo navegable del ecosistema ACC360 con cuatro niveles de experiencia:

1. **Página Principal** (`index.html`): identidad ACC360, banner general, accesos rápidos y novedades.
2. **Área Personal** (`area-personal.html`): cursos recientes, calendario, mensajes y accesos rápidos.
3. **Mis cursos** (`mis-cursos.html`): catálogo de cursos en tarjetas, buscador y filtro.
4. **Curso específico** (`curso-factorizacion.html`): prototipo detallado de *Factorización algebraica con ACC360* heredado y reorganizado desde la V1.2.

Se incluyen además dos cursos demostrativos (`curso-demo.html`) para validar que el ecosistema admite múltiples temáticas.

## Alcance
- Prototipo visual navegable, no instalación real de Moodle.
- No usa base de datos ni autenticación.
- El progreso del curso de Factorización es local/demostrativo.
- La identidad visual es propia de ACC360 e inspirada en la lógica de navegación de un EVA moderno.
